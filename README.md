# KidMarket

A front-end prototype for a kid-friendly marketplace.

## Run it
Open `index.html` in a web browser.

## What works
- Browse sample listings
- Search and filter listings
- Add a listing
- Listings persist in the browser using localStorage
- Responsive mobile layout
- Safety-focused UI

## Important before a real launch
This is only a front-end prototype. A real service involving children would need adult/guardian verification, age-appropriate privacy and safety design, moderation/reporting, secure authentication, payment handling, legal review, and compliance with applicable child-privacy and consumer-protection laws. Do not use this prototype to collect real children's personal information or payments.
